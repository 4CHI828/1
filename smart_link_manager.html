智能連結 Smart Link Manager 完整功能指南

1. 頂部工具列與「⋯」更多選單
稍後閱讀提醒：徽章顯示已到期筆數，點擊檢視
快速新增：自訂標題與點選標籤另存
更多選單：以下管理、顯示、匯出入、失效檢測等功能都收在這裡
分類管理：資料夾排序、標籤改名、去重
批次管理：多選移動、加標籤、標已讀
失效檢測：巡檢死鏈（再次點擊可停止）
顯示設置：字體縮放、縮圖模式、自動已讀
Markdown：一鍵複製當前清單為 MD 語法
主題切換：深色模式（太陽）/ 淺色（月亮）
重新整理：重整資料或「隨機靈感」重新洗牌
匯出 JSON：下載完整資料庫與資料夾備份
匯出 HTML：匯出瀏覽器通用標準書籤檔
智能匯入：支援 JSON 與瀏覽器 HTML 書籤
擴充功能：透過安裝說明取得 Chrome 擴充功能
2. 鍵盤與滑鼠快捷操作
Ctrl + V 頁面任意處直接貼上網址存檔
拖曳網址/檔案 直接拉進視窗即可存檔或匯入
Shift + 點擊 批次模式下「區間快速連選」
Ctrl + Enter 編輯摘要多行框內直接儲存
N / / 聚焦主網址框 / 聚焦搜尋框
B / ? 批次管理模式 / 開啟功能指南
Esc 清空搜尋框、關閉彈窗或退出批次模式
3. 全域貼上／拖放、混合文案提取與網址淨化
  • 全域 Ctrl+V 直存 & 外部拖放支援：未開啟彈窗時直接按 Ctrl+V，或從其他視窗將「網址」或「.json / .html 備份檔」直接拖進畫面任意處，即可自動存檔或匯入。
  • 手機 App 混合分享文案提取：直接貼上抖音、小紅書、YouTube 等帶有文字的分享段落，會自動分離出乾淨網址並將文案作為備用標題。
  • 追蹤碼深度淨化 & 8 秒防卡死：自動拔除各大平台追蹤參數；遇慢速網站逾 8 秒自動以網域快速存檔。
  • 重複連結智慧歸位 & 編輯重抓 ()：貼上重複網址可一鍵推至最上方並自動移入當前資料夾；編輯視窗點擊「重抓資訊」可隨時重新補齊標題、摘要與預覽圖。
4. 資料夾排序、標籤管理、自動去重與交集搜尋
  • 資料夾拖曳排序 & 全域標籤管理 ()：按住 可上下拖曳自訂資料夾順序；切換至「🏷️ 全域標籤管理」可將標籤全域改名（自動合併）或全域移除。
  • 歷史重複網址一鍵清理 (🧹 清理重複網址)：位於「📂 分類管理」底部，執行前會自動下載防呆備份檔，接著掃描書籤庫將相同網址合併標籤、累加點擊數並清除副本。
  • 卡片徽章與網站圖示 (Favicon) 快篩：點擊卡片上的資料夾、標籤徽章或左下角網站圖示 (Favicon) 即可立即過濾同類或同網域書籤。
  • 空白鍵多關鍵字交集搜尋 (AND) + 螢光筆高亮：搜尋框輸入多組字詞（如 react 教學）會取交集比對標題、網址、摘要與標籤，並安全套用螢光筆底色高亮。
5. 手機版防誤觸視圖、自動已讀與無限捲動
  • 三種瀏覽視圖與看板防衝突：支援瀑布流、列表與拖曳看板（手機端看板需「長按 0.15 秒」才觸發拖曳，不影響正常上下捲動）。
  • 三段式縮圖 () 與 200% 字體縮放：可切換「大圖 / 右側小圖 / 無圖」（手機端預設無圖）；字體支援 80% ~ 200% 無段縮放，並可開啟「點擊連結後自動標為已讀」。
  • 千筆書籤無限捲動分頁：採用每 60 筆智慧分頁與 IntersectionObserver 滑動自動載入，書籤破千筆依然瞬開不掉幀。
6. 獨立刪除復原佇列、批次貼標與併發失效檢測
  • 單筆刪除 5 秒獨立復原 (Undo Stack)：點擊垃圾桶免除確認彈窗，即使連續刪除多筆，每個右下角 Toast 都能獨立點擊「↩️ 復原」救回（自動堆疊，最多顯示 3 則）。
  • 零閃爍批次管理 ()：支援點擊卡片勾選、按住 Shift 區間連選、「批次已讀／未讀」、「🏷️ 批次加標籤」、「批次移動」與「批次刪除」。
  • 400% 提速的可中斷失效檢測 ()：導入併發池（Concurrency Pool）大幅提速，並即時顯示檢測進度（如 15/68）；檢測途中再次點擊即可安全停止並先行保存結果。
7. 原生 PWA 安裝、本機合併與跨瀏覽器書籤互通
  • PWA 原生安裝：若瀏覽器支援，頂部工具列將自動浮現「📥 安裝 App」按鈕，可將本工具安裝至桌面或手機主畫面，享有原生 App 體驗。
  • 本機登入雲端自動合併：若先在「本機模式」儲存連結，後續登入 Google 時會自動偵測並提示一鍵將本機未同步書籤合併至雲端帳號。
  • 雙格式自動去重匯入 () 與匯出：支援拖入或選取 .json 備份與各大瀏覽器匯出的 .html 書籤檔進行智能去重匯入；且支援匯出為瀏覽器標準的 bookmarks.html。
7. 巢狀資料夾、稍後閱讀提醒、隱私模式與標籤建議
  • 巢狀資料夾（最多 4 層）：在「管理資料夾與標籤」按 新增子資料夾、 移動到其他資料夾；同層內可拖曳排序。點選上層資料夾會一併顯示所有子資料夾內的連結。刪除資料夾時，連結與子資料夾會移到上一層。
  • 稍後閱讀提醒：卡片上的 或編輯視窗可設定提醒時間；到期後頂部鈴鐺會顯示筆數並出現橫幅。標為已讀後即視為完成。
  • 隱私模式（不抓取預覽）：於「顯示、閱讀與隱私設置」開啟後，不會把網址送到 Microlink、YouTube、Google favicon 服務，也不載入縮圖；失效檢測與重抓資訊會停用。
  • 標籤建議：依「同網域常用標籤」「既有標籤出現在標題內」「網域規則」「關鍵字」在新增與編輯時建議標籤；也可在設定中關閉儲存時自動套用。

Chrome 擴充功能

Chrome 不允許一般網站直接把 CRX 當成「一鍵安裝」。因此這裡改成安全的手動安裝流程，不會再出現「無法從這個網站新增擴充功能和應用程式」的誤導操作。

方式 1：下載 CRX
  1. 先下載擴充功能檔案。
  2. 開啟 Chrome 的 chrome://extensions/。
  3. 開啟右上角「開發人員模式」。
  4. 依 Chrome 版本支援情況，將 CRX 拖入擴充功能頁，或改用「載入未封裝項目」。
方式 2：開發測試

如果你有擴充功能原始碼資料夾，直接在 chrome://extensions/ 選「載入未封裝項目」即可。
