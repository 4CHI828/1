智能連結 Smart Link Manager 功能指南

鍵盤快捷鍵（非輸入狀態下）
Ctrl+V 頁面任意處直接貼上存檔
N 聚焦上方網址輸入框
/ 聚焦搜尋框快速檢索
B 開啟 / 關閉批次管理模式
? 開啟本功能說明視窗
Esc 關閉視窗或退出批次模式
全域貼上、混合文案提取與重新抓取
  • 全域 Ctrl+V 直存 & 混合文案提取：打開網頁直接按 Ctrl+V 即可存檔；貼上手機 App（抖音、小紅書、YouTube）帶文字的分享段落會自動分離出網址與標題。
  • 編輯視窗一鍵重抓 ()：在編輯連結視窗點擊網址旁的重新抓取鈕，可隨時重新補抓最新的網頁標題、摘要與預覽圖。
  • 重複連結偵測：若偵測到相同網址已存在，會提醒所在資料夾，並可選擇一鍵將舊連結更新時間推至最上方。
階層分類連動、搜尋高亮與狀態快篩
  • 資料夾 ➔ 標籤階層連動：選擇特定資料夾時，下方標籤列會自動只統計該資料夾內的標籤與筆數；支援直接點擊卡片上的徽章進行過濾。
  • 搜尋關鍵字高亮：輸入關鍵字時，瀑布流、列表與看板卡片中的命中字詞皆會自動以螢光底色高亮標示。
  • 狀態快篩與 5 種排序：支援篩選「僅看未讀／已讀／釘選／失效」以及 5 種排序方式（最新、最舊、最常造訪、標題 A-Z、隨機靈感）。
視圖切換、三段式縮圖與自動已讀設置
  • 三種瀏覽視圖：支援「瀑布流（多欄卡片）」、「列表視圖」以及可拖曳分類的「看板模式（📥 待讀 / ⭐ 精選 / ✅ 已讀）」。
  • 三段式縮圖 () 與 200% 字體縮放：可切換「頂部大圖 / 右側小方圖 / 極簡無圖」，並可開啟「點擊連結後自動標為已讀」。
獨立刪除復原、批次貼標與可中斷失效檢測
  • 連續刪除獨立復原 (Undo)：單筆刪除免確認彈窗，即使連續刪除多筆，每個右下角 Toast 都能在 5 秒內獨立點擊「↩️ 復原」救回。
  • 批次管理 () 與可中斷檢測 ()：支援批次加標籤、批次已讀、批次移動；失效檢測會顯示即時進度（如 12/45），再次點擊可隨時安全停止。
智能去重匯入（支援 Chrome 書籤與 JSON）
  • 雙格式自動去重合併 ()：支援匯入 .json 備份檔與瀏覽器匯出的 bookmarks.html 書籤檔，自動比對網址略過重複項目，不會覆蓋既有書籤。
