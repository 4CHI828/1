智能連結 Smart Link Manager 功能指南

鍵盤快捷鍵（非輸入狀態下）
N 聚焦上方網址輸入框
/ 聚焦搜尋框快速檢索
B 開啟 / 關閉批次管理模式
? 開啟本功能說明視窗
Esc 關閉所有彈出視窗或退出批次模式
智能存檔、網址淨化與防重複
  • 貼上自動存檔：在主輸入框貼上網址（Ctrl+V），系統會自動抓取網頁標題、摘要、預覽圖並識別社群平台標籤（YouTube、IG、FB、X、Threads），具備 8 秒逾時防卡死保護。
  • 追蹤碼自動淨化：存檔時自動拔除 utm_*、fbclid、igshid、si 等冗長追蹤參數，並驗證安全協定。
  • 重複連結偵測：若偵測到相同網址已存在，會提醒所在資料夾，並可選擇一鍵將舊連結更新時間推至最上方。
  • 快速新增 () 與擴充功能 ()：支援手動自訂標題／標籤另存，或搭配 Chrome 擴充功能一鍵收納當前分頁。
分類管理、搜尋與 5 種排序
  • 自訂資料夾 ()：支援新增專屬圖示資料夾、重新命名（）與刪除（刪除後內部連結自動歸回「未分類」）。
  • 動態色彩標籤：根據網站類型或自訂標籤自動產生專屬配色篩選器，支援複合搜尋。
  • 5 種排序切換：支援「🕒 最新加入」、「⏳ 最舊優先」、「🔥 最常造訪（自動統計點擊次數）」、「🔤 標題 A-Z」與「🎲 隨機靈感（點擊重新整理可再次洗牌）」，且釘選（）卡片永遠優先置頂。
視圖切換、三段式縮圖與 200% 字體設置
  • 三種瀏覽視圖：支援「瀑布流（多欄卡片）」、「列表視圖」以及可拖曳分類的「看板模式（📥 待讀 / ⭐ 精選 / ✅ 已讀）」。
  • 三段式縮圖 ()：可隨時切換「🖼️ 頂部大圖」、「🔲 右側小方圖」或「🚫 極簡無圖」模式，並提供即時預覽。
  • 無段式字體縮放 (80% ~ 200%)：拖曳滑桿或點擊快速檔位調整全區字體；當放大至 135% 以上時，瀑布流會自動減少欄數並展開雙行標題，確保大字體依然好讀。
卡片操作、批次管理與失效檢測
  • 直覺卡片互動：點擊卡片標題、大／小縮圖或網址皆可直接開啟網頁並累計熱度（🔥）；右上角提供「複製網址、釘選、標記已讀、編輯、刪除」快捷鈕。
  • 批次管理 ()：進入批次模式後，點擊整張卡片任意處即可勾選，支援「全選／反選」、「下拉選單批次移動資料夾」與「批次刪除」。
  • 失效連結檢測 ()：自動巡檢所有書籤（跳過需登入的社群網站），將無法連線或 404 的卡片標記紅色「失效」警示。
雲端／本機雙模式與資料備份
  • 雙模式切換：支援「Google 帳號雲端同步（Firebase）」與免登入的「本機測試模式（LocalStorage）」。
  • 多元匯出與備份：點擊 可將當前篩選清單複製為 Markdown 語法（自動轉義括號）；點擊 / 可匯出或還原完整 JSON 備份檔。
